AI is a force multiplier in my workflow — not a replacement for engineering.

- **Ownership:** I design the architecture, data model and security rules, and review every change before it ships.

- **Result:** you get enterprise-style features at a small-team cost and timeline.

## 🔄 How a Project Works With Me

```text
1. Discovery   →  We map your current workflow, pain points and roles (who does what)
2. Blueprint   →  Data model, modules and screens agreed before building
3. MVP sprint  →  A working version you can click through — usually within weeks, not months
4. Iterate     →  Weekly releases based on your team's feedback
5. Handover    →  Deployment, documentation, admin training and ongoing support options
```
